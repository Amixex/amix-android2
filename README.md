# Amix — Android (Kotlin + MediaPipe), модель внутри APK

Полностью офлайн ИИ-репетитор. Модель Qwen2.5 1.5B Instruct вшита прямо в APK:
ничего скачивать не нужно, интернет не нужен никогда.

## Как это работает на телефоне

1. После установки **один раз** (около минуты) идёт «Подготовка модели»: файл модели копируется
   из APK во внутреннюю память приложения. Интернет не нужен.
2. При каждом следующем запуске копирования нет. Остаётся короткая полоска «Запуск модели…»
   на несколько секунд: модель загружается в оперативную память. Убрать её нельзя.
3. Дальше чат отвечает без интернета.

Свободное место: нужно примерно **2 размера APK** (сам APK + копия модели во внутренней памяти).
Если места мало, приложение покажет, сколько ещё нужно освободить, и кнопку «Повторить».

## Сборка APK на GitHub (без Android Studio)

1. Создайте **новый** репозиторий (например, `amix-android`), лучше Private.
2. Загрузите в него всё содержимое этой папки (Add file → Upload files), включая папку `.github`.
   Перед коммитом убедитесь, что в списке есть пути вроде `app/build.gradle.kts` и
   `app/src/main/java/com/amix/tutor/ChatViewModel.kt`.
   Если `.github` не загрузилась: Add file → Create new file → имя `.github/workflows/build.yml`
   и вставьте содержимое файла `build.yml`.
3. Вкладка **Actions** → **Build APK (model inside)** (запустится сама, либо Run workflow).
   Сборка идёт 10–15 минут: скачивается модель (≈1,5 ГБ), собирается APK, выкладывается в Releases.
4. Откройте раздел **Releases** справа на главной странице репозитория → последняя сборка →
   скачайте **Amix-offline-debug.apk** (около 1,5–2 ГБ) → установите на телефон.

## Если что-то пошло не так

- **«Модель не скачалась»**: проверьте `MODEL_URL` в `.github/workflows/build.yml`. Если Hugging Face
  просит вход, создайте токен на huggingface.co/settings/tokens и добавьте его в репозитории:
  Settings → Secrets and variables → Actions → New repository secret → имя `HF_TOKEN`.
- **«APK больше 2 ГБ»**: GitHub Releases принимает файлы до 2 ГБ. Возьмите модель поменьше
  (например, Qwen2.5 0.5B в формате `.task`) и замените `MODEL_URL`.
- **Приложение закрывается при запуске модели**: не хватает оперативной памяти телефона.
  Нужна модель поменьше.
- **Новая сборка не ставится поверх старой**: debug-ключ у каждой сборки новый. Удалите старое
  приложение и поставьте новое (модель внутри APK, скачивать ничего не придётся).

## Файлы

- `app/src/main/java/com/amix/tutor/` — код приложения (`ModelDownloader.kt` копирует модель из APK).
- `app/build.gradle.kts` — модель в assets не сжимается; только arm64.
- `.github/workflows/build.yml` — сборка и публикация APK.
- Сама модель в репозиторий **не кладётся** (она в `.gitignore`): её скачивает сборка.

## Gradle Wrapper (необязательно)

Если файлов `gradlew`, `gradlew.bat`, `gradle/wrapper/gradle-wrapper.jar` нет, workflow сам установит
Gradle 8.9 и соберёт проект командой `gradle assembleDebug`.
